# The Adventures of Froggit the Frog
A text-based adventure game built with C++.

## About
The Adventures of Froggit the Frog is a text-based adventure game 
inspired by classic titles like Zork and Colossal Cave. Players 
navigate through a story where their choices shape the outcome, 
keeping the pure feel of classic text adventures.

## Tech Stack
- C++

## Features
- Choice-based narrative gameplay
- Multiple story paths
- Text-based interface inspired by classic adventure games

## Development
Developed as a school project in 2022.
